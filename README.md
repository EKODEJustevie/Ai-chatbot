# Ai-CCode

Programmation d'une intéligence artificiel en language C.
Ce projet est un projet type nouveaux sans reprnedre les codes de l'ancienne indusrtie  de l'ia visantt à créer une IA générative de type LLM totalement en language C.  
Objectif premier :   
  converser ;
  géneration de texte;
  recherche et argumentation logique sous 2 langues; 
  Transcription de language humain en code;
  Programmation et test de code ;
  auto modification et amélioration de son propre code ;
  
Il sera sous 2 version en Opensource et en original et ne contiendra pas de codé généré par une ia. 
pour chaques parties de code et modification elles serons associé à une description sous forme de commentaire et un shéma visuel ( organigramme ou logique déssiné)
